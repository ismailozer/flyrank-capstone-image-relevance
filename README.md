# FlyRank Capstone — AI Image Understanding & Content Matching Engine

A backend AI system that understands image libraries, generates structured metadata, semantically matches images to blog content, and safely rejects unreliable recommendations.

## Current Status

Phase 1 — Design

## Core Goals

- Structured image understanding
- Schema-validated AI output
- Low-confidence flagging
- Image and post embeddings
- Semantic similarity ranking
- Explainable mismatch guard
- Background batch processing
- AI cost tracking
- Human review workflow
- Evaluation with top-1 precision
